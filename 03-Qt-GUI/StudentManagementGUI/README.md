# StudentManagementGUI

这是一个使用 C++ 和 Qt 编写的学生信息管理项目，主要用于练习 C++ 基础、STL、面向对象设计以及 Qt 窗口之间的数据传递，c++代码请见Cpp-Learning-Journey\02-Cpp-OOP\StudentManagementSystem。

## 当前已经完成的内容

### 教师端

- 添加学生信息
- 删除学生信息
- 修改学生信息
- 查询学生信息

### 学生端

- 按学号查询个人信息

## 当前未完成的内容

- 登录界面的账号创建和密码设置
- 数据库存储，目前使用文本文件保存数据
