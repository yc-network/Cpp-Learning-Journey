# Cpp-Learning-Journey

这是我用来记录 C++ 学习过程的仓库。

目前大一刚结束，准备进入大二。之后会学习数据结构、计算机组成原理、计算机网络、操作系统等课程，所以想利用暑假把 C++ 基础打得更扎实一些。

相比只看语法，我更喜欢通过自己写项目来学习。这个仓库会保存我写过的项目、每天的学习记录，以及之后学习过程中留下的代码。
