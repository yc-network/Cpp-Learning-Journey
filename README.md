# StudentManagementSystem

## 项目日期

2026-08-05

## 项目简介

这是一个 C++ 面向对象练习项目。

主要用于学习：

- 类与对象
- 构造函数
- 初始化列表
- this 指针
- C++ 三文件工程结构


## 项目结构
StudentManagementSystem
├── Student.h
├── Student.cpp
└── main.cpp




## 已实现功能

- 创建学生对象
- 保存学生信息
- 输出学生信息
- 计算平均分
- 判断成绩等级
