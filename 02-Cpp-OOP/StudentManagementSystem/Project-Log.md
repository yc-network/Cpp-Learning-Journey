# StudentManagementSystem Project Log

记录 StudentManagementSystem 项目的开发过程。

---

# 项目开始

## 2026-08-05

开始第一个较完整的 C++ 项目。

最初目标：

通过实现一个简单的学生管理系统，练习：

- class
- 多文件项目结构
- 面向对象设计


完成：

- Student 类
- 基本学生信息保存
- 成绩计算
- 信息输出


第一次尝试将：

- .h 文件
- .cpp 文件
- main.cpp

组合成一个完整项目。

---

# 项目完善

## 2026-08-06

项目加入管理功能。

新增：

- StudentManager
- StudentUser


实现：

- 添加学生
- 删除学生
- 查询学生
- 修改学生信息


项目开始从：

“一个学生对象”

变成：

“多个对象之间协作的小型系统”。


学习：

- vector 管理多个对象
- 引用传递
- 指针返回对象


开始理解：

不同类应该负责不同事情。

例如：

- Student 负责描述学生
- StudentManager 负责管理学生集合

---

# 用户角色设计

## 2026-08-07

继续完善项目结构。

新增：

- TeacherUser


实现：

- 学生端查询
- 教师端管理


开始考虑：

- 用户操作
- 数据管理
- 类之间的关系


同时发现当前设计存在一些不足：

- 部分类职责划分不够清晰
- 数据管理和用户交互存在耦合


但是考虑到这是第一次完整设计多个类协作的项目，因此保留当前版本。

---

# 项目阶段总结

这是第一个完整的 C++ 多文件项目。

通过这个项目学习：

- 如何拆分类
- 如何让多个对象协作
- 如何使用 STL 容器
- 如何组织一个小型项目


项目中也发现了一些问题：

- 类设计还不够成熟
- 对软件结构理解还不够深入


这些问题不会马上通过继续堆功能解决。

之后学习更多 C++、STL、数据结构后，会在新的项目中继续改进。
